01顾客进门

先认识人，
再认识它。

一位宠主牵着狗走进店里。从这一刻起，系统要记住的不只是一个手机号，还有那只毛孩子。

第一次来，就留下一份完整的档案

新增会员时，宠主资料和宠物资料一起录入，老客户的宠物资料也能批量导入。下次再来，用电子会员卡、会员卡号、手机号，甚至只报一个宠物昵称，都能马上找到。

入会的门槛由门店自己定：扫码免费注册、充值折扣定级（充得越多折扣越高）、零售会员制的付费年卡，或按消费 / 积分累计升级，几种方式可以搭配使用。会员等级、升级制度、等级会员价都能自定义，不同品类还能对应不同折扣；再给会员打上标签，往后推送的活动就能分人而定。

让顾客愿意常来

充值不只是送金额：可以赠送商品或服务、积分或余额、优惠券，也可以给充值会员设定洗护折扣和商品折扣。赠送的金额和礼品还能分期返还并限制使用期限，返还周期长过储值消费周期，会员自然留得更久。

积分来自消费累计、每日签到（可递增）和抽奖，会员等级、会员日、生日还能设置多倍积分；用起来可以抵现、兑换优惠券或商品、参与抽奖。储值卡、次卡、月卡、季卡、购物卡与优惠券都可自定义，限定使用时间和消费品类。

收银台前，
一次结清所有的事。

结账，在哪台设备上都一样

Windows 收银机、iPad、安卓平板、手机都能收银，数据云端同步。商品分类可以自定义多级（主粮、美容、寄养……），有码商品和无码服务项目都能录入收银，整包商品也能拆零卖。

寄养期间顺手买的零食统一结算；宠物医院里，检查项目和治疗项目可以分开收银。

02把宠物照顾好

门店真正的功夫，
在服务里。

洗澡、美容、寄养、看病、打疫苗——每一项都关乎一个小生命，也关乎宠主的信任。

洗护美容：顾客自己约，前台一键接

顾客在宠物小程序里看到空闲时段，选好服务项目，指定或不指定美容师，自助下单。门店这边设好班次排班、每个时段的最大接待量和可提前预约的天数，选择付费预约或免费预约，并用短信提醒。

新预约一到，收银前台弹出提醒，在预约看板上按美容师和时段一目了然；宠物到店做完服务，直接收款。

寄养：像酒店一样管，像在家一样看得见

在后台划好寄养区域（比如喵区、汪区）和房间数，收银端选房登记、收取定金，打印可自定义的寄养协议，结账时自动扣除定金。收费按小时或按天自定义，寄养期间的消费统一结算；到期红灯提醒，逾期也会继续自动计时。

对接萤石等支持流媒体的摄像头（免费对接）后，宠主在会员中心点开「寄养直播」就能看到自家宠物，无需额外下载 APP。

宠物医院：从挂号到回访，每一步都留档

前台为宠物挂号，选就诊医生和挂号项目（内诊、外诊、特需专家）；医生在诊疗后台记录主诉与体况、开检查化验单，根据报告诊断并把结果存档；再开具处方或组合处方（可预设处方组），填写医嘱并预约下次回访。诊疗报告可以打印，回访到期有提醒，历史诊疗随时可查。

医疗项目分为商品服务、检查化验、处方手术、挂号项目四大类，检验项目和各类卡项可自定义；药品支持批次管理与保质期提醒，项目统计与药品进销存一并管理。

该打疫苗了？系统比店员先记得

为驱虫、疫苗商品设好提醒周期，系统按消费时间自动顺延，到期通过短信或微信提醒宠主；特殊情况可以手动临时调整周期。不只是疫苗，所有周期性商品都能这样设置。

店员也可以在会员详情里新增服务记录并设提醒时间，到期弹窗提醒回访。积分和余额变动、充值、分销佣金到账、优惠券发放，以及优惠券和次卡临期，同样会自动通知会员。

门店，开到顾客手机里

宠物商城小程序一键同步门店商品，库存实时同步，不用重复录入；可以自定义装修、设置线上专属促销。顾客随时逛店下单，外卖直送到家，服务项目也能看空闲时段自主预约。

顾客支付即会员，在电子会员中心查看消费记录、余额、积分、优惠券和卡项，还能自助充值；门店可定时、定向推送优惠券，提供远程问诊客服。每日签到得积分、积分抽奖兑换礼品或抵现，配合秒杀、拼团、限时砍价、团购、邀请有礼、优惠券裂变，再设置推广员让顾客参与推广。开通小程序高级营销工具后，还有养成游戏：顾客圈养虚拟宠物，做任务换能量和里程，兑换优惠券、次卡或礼品。

04店里的人和货

人有干劲，
货有着落。

好的门店，员工知道自己做了多少，老板知道货从哪来、还剩多少。

提成算得清，员工才愿意多做一步

普通商品按固定比例或固定金额提成；美容师和助理协同完成一个项目，先按设定的分摊比例分业绩，再各自乘以提成比例；充值也能提成。会员 A 由员工 B 引导注册后，在线上商城自主购物，B 按规则获得归属提成；会员到店消费，则由实际服务的人提成。店长适用按全店销售额的阶梯提成，也可按品牌或分类设阶梯比例。

员工用CRM 小程序凭独立注册码或手动提交资料邀请顾客注册，长期绑定归属关系；把商品和海报分享到朋友圈，顾客下单自动计算提成。回访会员、一键转发优惠券，把洗护 / 体检报告一键生成发到宠主微信，也能看自己的业绩提成和销售排名。

和推广员的区别：推广员以门店会员身份拉新、独立结算佣金（员工需先注册为会员，从商城入口拉新）；CRM 以员工身份拉新，提成直接计入员工绩效。门店还可以管理导购员，配合预约服务排班。

货，从进门到卖出都有数

自带宠物商品资料库，一键导入；为商品设库存上下限，报损自动统计，企业版支持进货批次管理。进货、调货、出库、退货给供货商、报损都在一套流程里。

采购按部就班：商品部制定采购单 → 审核人员确认 → 采购按供货商确认的数量生成进货单 → 仓库按实际到货核对入库。赠品和多批不同进价的商品，系统自动加权平均成本。门店按库存上限生成订货单，总部审核并匹配仓库库存、调整配货量，仓库出库，门店按货流单入库。

供货商资料、结算进度、进货价格分析、结算记录与二次对账、金额汇总，一处查清。盘点支持全店盘点和部分盘点：手机下载银豹盘点 APP 即可多人协作；也可以选用适配的 PDA，比手机摄像头更灵敏，但会增加采购成本，多数门店直接用手机。
